ПЛЕЙЛИСТ ПО УМОЛЧАНИЮ
=====================
Кладите сюда mp3-файлы. Называйте их "Исполнитель - Название.mp3" —
из имени файла приложение само возьмёт и исполнителя, и название.

Список файлов (playlist.json) обновляется САМ: после загрузки или
удаления mp3 на GitHub запускается Action "Update default playlist"
(вкладка Actions), через ~30 секунд playlist.json готов.

Если Action не используется — впишите имена файлов в playlist.json вручную:
{ "tracks": ["Artist - Song.mp3", "Other - Track.mp3"] }
